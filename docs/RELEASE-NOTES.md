# Cue 0.1.16

- Локальная расшифровка GigaAM v3: микрофон и системный звук обрабатываются на компьютере, чат и анализ работают через выбранный API. Установка модели доступна в настройках; требуется Python 3.12+ и около 900 МБ для весов.
- «Помоги» и «Что ответить» учитывают вопрос с любого аудиоканала и текст в поле ввода. Автопомощь включается отдельно.
- Ответы разбиты на короткие абзацы: суть, конкретный механизм и одно полезное пояснение или пример. Жёсткого ограничения слов нет. Резюме сохраняет все существенные пункты.
- Последние фразы обрабатываются перед сохранением. RAW сохраняется до генерации итога; при сбое итог можно повторить из незавершённых встреч. Промежуточное резюме не завершает запись.
- Исправлены перетаскивание панелей, обрезанные тени, расположение кнопок и стрелок списков. Настройка анимаций управляет переходами и иллюстрацией пустого чата.

## Установка

- Windows x64: установщик `.exe`.
- macOS Intel: архив `mac-x64.zip`.
- macOS Apple Silicon: архив `mac-arm64.zip`.

Веса GigaAM скачиваются отдельно и не входят в пакеты. При локальной расшифровке аудио не отправляется в API, но текст вопросов, контекст встречи и запрошенный экран передаются выбранному AI-провайдеру.

Пакеты macOS не подписаны и не нотарифицированы. Сборки проверяются на macOS и Windows; физический микрофон и звук конкретного приложения созвонов требуют проверки на устройстве. Контрольные суммы доступны в `SHA256SUMS.txt`.
