# Окна, чат и расшифровка

Каждую панель Cue можно перетаскивать за заголовок на любой подключённый монитор. `Shift` при начале перетаскивания перемещает все видимые панели вместе. Размер меняется за края; положение и размер сохраняются между запусками. В настройках можно отключить перетаскивание или сбросить расположение. Сброс возвращает панели на основной монитор и сохраняет их размеры.

Панели чата, управления записью, настроек, каталога встреч и знакомства с Cue — отдельные окна. Скрытие панелей не останавливает запись. После отключения монитора заголовки оставшихся за пределами экрана окон возвращаются в доступную область.

## Экран для ИИ

Список «Экран для ИИ» в заголовке чата определяет, какой монитор попадает в запросы анализа экрана. При первом запуске выбран основной монитор, затем выбор сохраняется. Перемещение Cue на другой монитор не меняет этот выбор. Если выбранный монитор отключён, запрос со скриншотом завершится ошибкой: нужно выбрать другой экран. Звук встречи по-прежнему поступает из общего системного аудиоканала.

Показатели записи находятся в верхней строке рядом с выбором экрана и остаются видимыми при свёрнутой расшифровке. Название и разрешение выбранного монитора доступны в подсказке списка.

## Расшифровка и чат

- Заголовок расшифровки переключает компактный блок и свёрнутую строку. Кнопка справа раскрывает текст до поля ввода; чат временно скрывается.
- Новая встреча начинает запись с компактным блоком высотой до 160 px. Последующие реплики не меняют выбранное состояние. Если прокрутить историю вверх, новые фразы не возвращают её вниз. «К последним репликам» возобновляет слежение.
- Текст доступен для выделения и копирования, без ручного редактирования. Соседние фразы одного говорящего с паузой до двух секунд объединяются только визуально. Исходные фрагменты остаются отдельными.
- Ручной запрос, включая горячую клавишу, возвращает чат. Автоматический ответ оставляет расшифровку раскрытой и показывает кнопку «Новый ответ в чате». Черновик сохраняется при переключении.
- Кнопка копирования включает расшифровку и сообщения, даже если часть интерфейса скрыта.
- Пользовательские сообщения стали компактнее. В заголовке ответа ИИ показана модель и небольшой бейдж режима. Если API сообщает имя модели, используется оно; иначе отображается запрошенное имя с пояснением в подсказке. Смена настроек не переписывает модель предыдущих ответов.

## Автоматические подписи говорящих

Микрофон соответствует подписи «Вы», системный звук — «Собеседник». Cue сопоставляет совпадающие слова в пересекающихся по времени фрагментах двух каналов. Совпавшая часть остаётся в системном канале; уникальные слова микрофона сохраняются. Поздний результат распознавания может исправить уже показанный дубль. Повторение той же фразы в другое время сохраняется.

Это сопоставление аудиоканалов и текста, без идентификации голосов. Отличающиеся результаты распознавания могут оставить эхо; одновременное произнесение одинаковых слов может ошибочно считаться эхом. Два человека рядом с одним микрофоном или несколько голосов в системном звуке не разделяются по личностям. Локальная GigaAM по-прежнему не отправляет аудио через API.

Журнал сессии версии 2 хранит `sourceTranscript` с исходными результатами обоих каналов, `transcript` с согласованными репликами и `transcriptRevision`. UI, запросы ИИ, RAW и итог используют согласованный текст. Старые журналы читаются без удаления предполагаемого эха, если в них нет времени окончания аудиофрагмента.

## Проверки

`npm test` проверяет геометрию в DIP, отрицательные координаты мониторов, миграцию, сопоставление каналов, сохранение и восстановление журналов, API-маршруты и метаданные модели.

`npm run test:ui` проверяет отдельные окна, три состояния расшифровки, прокрутку, клавиатуру, черновик, копирование скрытого текста, карточки ИИ и настройки. Скриншоты синтетического диалога сохраняются локально в `.local-stt/qa/workspace`.

`npm run test:behavior` проверяет реальные окна Electron через IPC с заданными координатами курсора: перенос между подключёнными мониторами, перемещение группы, размеры и восстановление. Отключение монитора и уменьшение движения моделируются. `npm run test:assistant` проверяет сохранение встречи и запись со скрытой панелью с тестовыми аудио/API-ответами. `electron test/local-stt-flow.js` дополнительно использует установленную локальную GigaAM и тестовые WAV-файлы; чат направлен только на локальный тестовый сервер.

Физическое перетаскивание мышью между мониторами с разным масштабом, реальное отключение дисплея, живой разговор с динамиками и микрофоном и работа окон на macOS требуют отдельной проверки на устройствах. Успешная сборка не подтверждает эти сценарии.

Координаты окон и курсора обрабатываются в DIP без повторного умножения на масштаб. Основа: документация Electron [screen](https://www.electronjs.org/docs/latest/api/screen), [BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window) и [desktopCapturer](https://www.electronjs.org/docs/latest/api/desktop-capturer); проверки выполняются на закреплённой в проекте версии Electron.
