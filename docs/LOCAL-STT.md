# Локальная расшифровка GigaAM

Cue может разделять две задачи:

- **Расшифровка:** локальная GigaAM v3 E2E RNN-T на CPU или прежний провайдер через API.
- **Чат, «Что ответить?», подсказки и итог:** выбранный ИИ-провайдер с вашим API-ключом.

## Настройка

1. Откройте настройки Cue → «Расшифровка» → «Локальная GigaAM».
2. Нажмите «Установить GigaAM · 900 МБ». Нужен установленный Python 3.12+ в PATH. Cue создаст отдельное окружение в папке своих настроек, скачает модель и проверит контрольные суммы. Установка требует интернет; распознавание после неё работает без интернета.
3. Если у вас уже есть модель и окружение с `onnx-asr`, укажите папку модели и путь к Python. Нажмите «Проверить».
4. В карточке ИИ-провайдера оставьте ключ, адрес API и модели чата. Модель расшифровки API в локальном режиме не нужна. Доступны также Anthropic и NVIDIA, которым не требуется поддерживать распознавание аудио.
5. Нажмите «Готово», затем включите запись.

Микрофон и системный звук поступают отдельно: «Вы» и «Собеседник». Это разделение источников, а не определение каждого участника в общем системном аудио.

## Во время встречи

Распознанные фразы появляются в живом конспекте. Cue ждёт паузу около 0,4 секунды или обрабатывает непрерывную речь фрагментами примерно по 4,4 секунды. К этому добавляется время вычисления на вашем ПК. Это обработка коротких фрагментов, а не пословный стриминг GigaAM; границы фрагментов могут снижать точность.

Пишите вопросы в чат или нажимайте «Что ответить?». Перед ручным вопросом Cue дожидается текущего распознавания и обрабатывает накопленный звук. Последние шесть пар сообщений переписки передаются при следующем вопросе; сама запись разговора продолжает накапливаться отдельно. «Помоги» даёт разовый ответ, а отдельная «Автопомощь» включает автоматические подсказки на вопросы собеседника.

При остановке Cue дожидается текущих распознаваний, обрабатывает оставшиеся фрагменты, сохраняет RAW, затем отправляет полный текст на итоговый анализ. Если ответ в чате ещё генерируется, итог ждёт его окончания. «Сохранить RAW» завершает запись без запроса нового AI-итога.

## Где находятся файлы

Windows: `%APPDATA%\cue\gigaam\venv` и `%APPDATA%\cue\gigaam\model`. Пути можно заменить в настройках. Модель остаётся отдельно от установщика Cue.

Обязательные файлы выбранного варианта:

```text
config.json
v3_e2e_rnnt_vocab.txt
v3_e2e_rnnt_encoder.onnx
v3_e2e_rnnt_decoder.onnx
v3_e2e_rnnt_joint.onnx
```

Один `gigaam_v3.onnx` не является полным комплектом: в `onnx-asr` это предобработка звука. Python-скрипты движка берутся из установленного пакета, а не из папки с найденными файлами модели.

## Ошибки и данные

В локальном режиме Cue не отправляет аудио в API и не переключается на облачное распознавание при ошибке. При неудаче повторяется тот же фрагмент; после второй неудачи запись останавливается с сообщением. Ошибка попадает в журнал встречи. Непризнанный фрагмент не превращается в выдуманную реплику; исходное аудио не сохраняется для дальнейшего восстановления.

Очередь ограничена 30 секундами звука на источник. При превышении Cue явно останавливает запись, сохраняя уже принятый текст; последний не принятый фрагмент отмечается ошибкой. Менять способ распознавания во время записи и сохранения нельзя.

Текст разговора и переписки передаётся выбранному ИИ-провайдеру при вопросах, автоматической помощи и итоговом анализе. Снимки экрана по-прежнему используются в соответствующих функциях. Локальная расшифровка не означает, что весь AI-помощник работает офлайн.

## Разработка и проверка

`npm test` проверяет маршрутизацию без облачного fallback, жизненный цикл процесса, очередь и сохранение настроек. `npm run test:ui` проверяет интерфейс Electron.

`electron test/local-stt-flow.js` запускает настоящий GigaAM и Electron с тестовым API чата. Укажите `CUE_LOCAL_STT_ROOT` (по умолчанию `.local-stt`) с `venv`, `model`, `probe.wav`, `reply.wav`. WAV должны быть PCM16 mono 16 kHz с двумя различными русскими фразами. Этот тест проверяет два канала, историю чата, остановку во время ответа и сохранение итога; реальные устройства и экран в нём отключены. Его успешное прохождение не подтверждает микрофон или loopback в конкретном приложении созвонов.

Для изоляции документов в проверках предусмотрена переменная `CUE_DOCUMENTS_DIR`. Веса и окружение разработчика исключены из Git и сборки.
